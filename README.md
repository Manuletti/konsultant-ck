# Консультант ЦК

Текстовая игра по мемуарам консультантов ЦК КПСС, 1963–1979 гг. Вымышленный герой проходит 14 сцен: от приглашения в группу Андропова до декабря 1979 г. После каждого решения показано, как это событие описывают мемуаристы, документы и историки, со ссылками на страницы. Строка, похожая на ваш выбор, подсвечена. В конце — художественный эпилог (август 1991 г.), собранный из ваших решений, и одна из семи концовок по реальным траекториям.
