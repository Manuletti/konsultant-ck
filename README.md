# Консультант ЦК

Текстовая игра по мемуарам консультантов ЦК КПСС, 1963–1991 гг. Вымышленный герой проходит около 20 сцен: от приглашения в группу Андропова до декабря 1991 г. (некролог Брежнева, сбитый «Боинг», предложение стать помощником Горбачёва, речь в ООН, Форос, флаг над Кремлём 25 декабря — по дневникам Черняева, мемуарам Шахназарова и Бовина; для тех, кто ушёл на телевидение, — сцены «Международной панорамы» 1981 и 1985 гг.). После каждого решения показано, как это событие описывают мемуаристы, документы и историки, со ссылками на страницы. Строка, похожая на ваш выбор, подсвечена. Показатели работают: часть решений требует нужного уровня, рискованные решения выпадают по шансу от показателя. Доверие 0 — увольнение, но при круге от 6 героя пристраивают рядом («Известия», институт), откуда его могут позвать обратно спичрайтером, как Бовина. В начале герой выбирает кредо (шестидесятник-обновленец, государственник, интернационалист); показатель «Убеждения» растёт, когда решение совпадает с кредо, и падает, когда противоречит ему. Убеждения 0 — конец игры («двоемыслие»). Показатель 8 даёт особое умение («Золотое перо», «Свои люди», «Ближний круг», «Твёрдость») и открывает особые решения; каждые два листа в аппарате слабеет круг, вне аппарата — доверие. К сценам 1967–1979 добавлен взгляд «с другой стороны океана» (Киссинджер, ЦРУ, американская пресса, Госдеп). В конце — художественный эпилог (январь 1992 г.: как герой принял или не принял новую страну) из ваших решений и одна из одиннадцати концовок (две проигрышные; по линии ИМЭМО — путь Примакова), у каждой своя гравюра; в финале — архивная справка с описью документов вашего «личного дела». В ключевых сценах (дачное сидение, запись беседы, ОСВ, Ангола, соя, Афганистан, некролог, речь в ООН) герой сам правит текст документа: выбирает формулировки, а смелые места на читке оставляют или вычёркивают с пометкой на полях; в сценах «Международной панорамы» вместо правки — монтажный лист (кадр, подпись, закадровый текст).

- `konsultant.html` — вся игра в одном файле: сцены (`SCENES`), концовки (`ENDINGS`), эпилог (`OPEN`, `CLOSE`, `epilogue()`), анимированные иллюстрации (`ILL`, inline SVG + CSS), движок (`checks()`, `choose()`). Открывается в браузере.
- Источник материала — вики архива РГГУ-ИВИ: матрица «событие × мемуарист», реестр консультантов, страницы работ И. М. Тарбеева.
- `konsultant-debug.html` — локальная отладочная копия, в git не входит.
- `sync-to-wiki.sh` — копирует игру в вики (`_wiki/Консультант ЦК (игра).html`).
